Innovation 1: Per-Land-Cover-Class Scale Calibration

Semantic-aware affine regression overcoming non-uniform depth bias across mixed urban and vegetation terrain.

1. The Need for Class-Specific Calibration

A single global affine fit between Stage 1's relative height and the SRTM reference assumes the relative-to-absolute relationship is uniform across an entire scene. Our own Stage 1 evaluation showed this assumption does not hold: building and tree classes exhibited systematically different relative-height error characteristics than flat ground and road pixels, once broken out per class rather than averaged across the whole tile.

2. The 6-Class Semantic Affine Model

DepthWizard fits independent affine parameters for each of GAMUS's six land-cover classes (ground, low-vegetation, building, water, road, tree):

srtm ≈ a_k · h_rel + b_k   for each class k, fit independently

Each (a_k, b_k) is an ordinary least-squares fit (numpy.linalg.lstsq) restricted to that class's valid pixels, not a robust regression — the dataset does not currently warrant the added complexity, and outlier handling is instead done structurally: any class with fewer than 30 valid pixels in a given tile is too small to fit reliably, so those pixels fall back to a single global affine fit (computed once, over all classes) rather than producing an unstable per-class estimate from too little data.

3. Measured Accuracy Gains

In a synthetic multi-bias test (constructed to have a known, different ground-truth bias per class), per-class calibration reduced error by roughly 91% relative to a single global affine fit over the same data. This is the calibration stage's own, isolated contribution — distinct from the depth backbone's own fine-tuning gains (v3: building −44%, tree −35% vs. zero-shot, reported in Depth Backbone), which happen upstream in Stage 1 and should not be conflated with what per-class calibration adds on top.

On a real GAMUS test tile run end-to-end through Stages 1→2, most per-class affine slopes came out near-zero (ground a=0.0017, low-vegetation a=−0.0004, building a=−0.0179) — meaning the fit is largely predicting each class's constant mean height rather than meaningfully using Stage 1's pixel-level relative-height signal. Only tree (a=0.08), road (a=0.12), water (a=0.29), and unlabeled (a=0.18) leaned on real signal. This is a known limitation of single-tile calibration — narrow within-class height variance on one tile — flagged here rather than presented as a clean result: the calibrated DSM's overall mean matching the ground-truth mean almost exactly on that run is an artifact of this near-zero-slope fitting, not evidence of pixel-level accuracy.
